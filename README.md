# MAZETEST 2

the long awaited sequel

## Python Depencencies

* pygame-ce (NOT pygame because it throws errors)
* json, os, csv, math, and sys should be preinstalled (you dont have to install them)
* ~~antigravity~~

## Installation
1. Get python (any version as long as you use pygame-ce)
2. Install the required depencencies (listed above)
3. Run `git clone https://github.com/philoxy/MazeTest2.git` to get all the game files in your current working directory (or if youre too scared to use a terminal, you can click the green code button to download the game files in a zip and extract it)
4. Go into the "MazeTest2" folder and then run `python3 main.py` to run the game. The game should then start (as long as your <a href="https://xkcd.com/1987/">python environment</a> isnt messed up)
