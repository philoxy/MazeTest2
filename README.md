# MAZETEST 2

the long awaited sequel to <a href="https://philoxy.github.io/programmer/#ti-84-ce-games">MAZETEST</a>, which on its own is a sequel to <a href="https://philoxy.github.io/programmer/#ti-83-games">THVI</a>

## Installation
### From source
1. Get <a href="https://www.python.org/">python</a>
2. Install pygame-ce (not regular pygame because it gives errors)
3. Run `git clone https://github.com/philoxy/MazeTest2.git` to get all the game files in your current working directory OR click the green code button, download the .zip file, and extract it
4. Go into the "MazeTest2" folder and then run `python3 main.py` to run the game. The game should then start!

### Binaries
Compiled binaries are available in the releases tab, so you can run them easily without having to setup anything!
Just go into the Releases tab, download the .zip file of the latest version and extract it, go into the folder corresponding to your platform, and run the game.
NOTE: macOS and macOS Intel versions don't work yet, as they require code signing or whatever im too lazy to do it now
